How to add this to your website

This synthesizer is 100% client-side JavaScript. You can drop it into any project without needing a backend server.


  • Add a link to Talk Engine to your site. You can also download this file and host it yourself.

    <script src="https://njs.dev/talk/talk_engine.js"></script>

  • If you use the default wiring, include this input element:

    <textarea id="textInput" rows="5" cols="40">Hello world.</textarea>

  • Buttons to control speech playback:

    <button id="playBtn">Speak</button> <button id="stopBtn">Stop</button>

  • An optional status line to show current state:

    <p id="statusLine">Status: Idle</p>

  • Or call it directly from JavaScript without requiring specific element ids:

    window.WebTalk.speak("Hello from local browser TTS"); window.WebTalk.stop(); window.WebTalk.configure({ basePitch: 96, pace: 1.0 });
