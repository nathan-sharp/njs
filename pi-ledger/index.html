What Pi Actually Is

Pi, written as π, is the ratio of a circle's circumference to its diameter. That ratio is the same for every circle, no matter how large or small it is.

Pi is irrational, which means its decimal expansion never ends and never settles into a repeating pattern. It also appears in many parts of mathematics, engineering, physics, and statistics because circles, waves, rotations, and periodic systems all turn up in the real world.

In simple terms, if a circle has circumference C and diameter d, then π = C / d. This page uses a locally computed reference sequence so the comparison stays on your device.

How the Score Works

The page compares the uploaded digits against a high-precision local reference and counts how many leading digits match before the first mismatch.

If your file contains more digits than the built-in reference range, only the first portion of your file is compared and the page tells you that limit.

Privacy and processing

Your file stays on this device. The page reads the text locally, strips out non-digit characters, and performs the match in JavaScript without sending the data anywhere.
