LO 3: Calculus

Calculus is the mathematical study of continuous change. In engineering, it allows us to analyze dynamic systems, find maximum and minimum values (optimization), and calculate areas and volumes. At SCQF Level 6, you will be introduced to the two main branches: differentiation and integration.

Differentiation

Differentiation is used to find the rate at which a quantity is changing. The result of differentiating a function is called the derivative, often denoted as dy/dx or f'(x). Geometrically, it represents the gradient of the tangent to a curve at any given point.

Basic Rule for Polynomials: If y = axn, then dy/dx = anxn-1.

Example in Engineering: If the displacement (s) of an object over time (t) is given by the function s(t) = 5t2 + 3t, the velocity (v), which is the rate of change of displacement, is the derivative:

  • v(t) = ds/dt
  • v(t) = 2(5)t2-1 + 1(3)t1-1
  • v(t) = 10t + 3

Integration

Integration is the reverse process of differentiation. It is used to find the accumulation of a quantity, such as calculating the area under a curve, volume, or total work done by a variable force. The integral symbol is ∫.

Basic Rule for Polynomials: The indefinite integral of axn is (a/(n+1))xn+1 + C, where C is the constant of integration.

Example in Engineering: If a force (F) applied to an object varies with distance (x) according to the function F(x) = 4x, the work done (W) in moving the object from x = 0 to x = 3 is the definite integral of the force function over that interval:

  • W = ∫03 (4x) dx
  • Find the integral: (4/2)x2 = 2x2
  • Evaluate at bounds: [2(3)2] - [2(0)2]
  • W = 2(9) - 0 = 18 Joules
