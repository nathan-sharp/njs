LO 2: Basic Addition

Addition is when we put things together to make a bigger number. It is one of the most important things we do with numbers!

Adding One

When we add one to a number, we just count up to the next number. Let's try some!

Example: If you have 1 apple and you get 1 more apple, how many do you have?

  • 1 + 1 = 2 apples!

Putting Sets Together

We can add bigger groups too. When we use the "+" sign, it means "plus" or "add". The "=" sign means "equals" or "is the same as".

Example: Imagine you have 3 red cars and 2 blue cars.

  • Let's count the red ones: 1, 2, 3.
  • Now let's count the blue ones: 1, 2.
  • If we count them all together: 1, 2, 3, 4, 5.
  • 3 + 2 = 5 cars!
