The OpenCAD Standard

OpenCAD GitHub Current Working Draft

The OpenCAD Standard is a cutting-edge protocol designed to facilitate seamless collaboration and data exchange in cloud-native CAD environments. By leveraging WebDAV for file management and introducing granular resource locking, OpenCAD enables multiple users to work concurrently on complex assemblies without conflicts. And allows the same file to be accessed and modified using different software applications.

WebDAV Concurrency & Granular Resource Locking

Traditional desktop CAD software relies on monolithic, filesystem-level file locks (`.LNK` or `.LOCK` temporary files) that freeze entire assembly files the moment a single user opens a part. This prevents concurrent engineering and forces teams into rigid, serialized workflows.

OpenCAD decouples the geometric payload from synchronization metadata:

  • Sub-Assembly Level Locking (`PROPPATCH` & `LOCK`): By extending the HTTP/1.1 WebDAV specification (RFC 4918), OpenCAD allows client applications to request exclusive or shared write locks (`Exclusive Write / Shared Read`) on specific sub-components, sketches, or parameter tables without locking the parent assembly structure.
  • Cross-Application Universal Schema: Whether an engineer is modeling parametric solids in an open-source desktop client or reviewing boundary representations (B-Rep) in a WebGL browser viewer, the OpenCAD protocol ensures deterministic delta synchronization across heterogeneous software platforms.
