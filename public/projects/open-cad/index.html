The OpenCAD Standard

OpenCAD GitHub | Current Working Draft

The OpenCAD Standard is a cutting-edge protocol designed to facilitate seamless collaboration and data exchange in cloud-native CAD environments. By leveraging WebDAV for file management and introducing granular resource locking, OpenCAD enables multiple users to work concurrently on complex assemblies without conflicts. And allows the same file to be accessed and modified using different software applications.

If you have any questions, suggestions, or would like to contribute to the development of OpenCAD, please feel free to reach out to me at contact@njs.dev.
