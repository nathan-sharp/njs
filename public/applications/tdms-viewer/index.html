What is LabVIEW TDMS?

The Technical Data Management Streaming (TDMS) file format was created by National Instruments (NI) to provide structured, high-speed data logging for LabVIEW, DIAdem, and DAQmx test and measurement systems. Unlike plain text CSV files, TDMS uses a structured binary layout that allows logging gigabytes of high-frequency sensor telemetry at tens of thousands of samples per second without disk write bottlenecks.

Three-Level Hierarchy

TDMS files organize information into a logical tree structure with three distinct object tiers:

  • File (Root /): Contains file-level metadata such as test title, author, date, LabVIEW version, and experiment notes.
  • Groups (/'Group Name'): Logical containers that group related measurement channels together (e.g., "Engine Sensors", "Voltage Grid", "Acoustic Stream"). Each group can carry its own custom properties.
  • Channels (/'Group'/'Channel'): Individual measurement series containing raw binary arrays (integers, double-precision floats, timestamps, strings) along with channel properties like unit strings (unit_string), descriptions, and scaling factors.

Binary Segment Structure (Lead-In Header)

A TDMS file is composed of a continuous sequence of binary blocks called segments. Every segment begins with a fixed 28-byte Lead-In header:

  • Tag (4 bytes): Always ASCII TDSm, uniquely identifying a valid TDMS block.
  • ToC Bitmask (4 bytes): Table of Contents flags indicating whether the segment contains metadata (kTocMetaData), raw measurement data (kTocRawData), DAQmx raw layouts, or interleaved arrays.
  • Version Number (4 bytes): Format revision (e.g., 4713 for TDMS 2.0).
  • Offsets (16 bytes): Two 64-bit unsigned integers indicating the byte offset to the raw data segment and the byte offset to the next segment in the file, allowing instantaneous random access without scanning the entire file.

Why Local Browser Processing?

Test engineers often deal with confidential prototype telemetry or massive multi-megabyte datasets. This TDMS Viewer processes your data entirely on your device using JavaScript ArrayBuffer and DataView APIs. Zero bytes are sent to any external server or cloud, guaranteeing 100% data privacy and instantaneous analysis.
