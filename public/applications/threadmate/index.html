ThreadMate

The ultimate thread calculator and reference tool.

ThreadMate is a blazing-fast native Android app for machinists and engineers. It provides instant offline calculations, tolerances, and thread specifications for Unified Inch (UN), ISO Metric, NPT, and ISO 7-1 (BSPT) threads.
