Inside a .UWU Archive & Manifest Structure

A `.uwu` file is not a proprietary black box; it follows an open, predictable binary packaging layout structured for zero-overhead execution:

  • Header Manifest (`manifest.json`): The leading bytes of every archive contain a JSON manifest defining the unit name, semantic version, minimum required P.A.W.S. API level, and exact execution command (`entrypoint`).
  • Packaging Automation (`make_native.py`): Developers can build custom `.uwu` packages using our Python build script (`make_native.py`). The script validates the entrypoint syntax, calculates SHA-256 integrity hashes for all bundled resources, and concatenates the header and tar stream into a single executable artifact.
