Unified Wrapper Unit

The Unified Wrapper Unit (.uwu) is a container format designed to solve the "it works on my machine" problem by standardizing the packaging of application logic, assets, and runtime requirements, similar to how Docker solves it. However unlike Docker, which virtualizes an entire OS filesystem, a .uwu file focuses on application portability through a unified interpreter called P.A.W.S. (Platform Agnostic Wrapper Service).

Install the Runtime (P.A.W.S.)

Just like you need a PDF reader to open .pdf files, you need the Platform Agnostic Wrapper Service (PAWS) to open .uwu files.

Windows Users
  1. Click here to download the installer
  2. Run the install script in a terminal or command prompt
Linux and macOS Users
  1. Open your Terminal.

  2. Run the universal install script:

    curl -L https://njs.dev/media/paws/linux_install.sh | bash

3. Verify installation by typing paws --version. You should see something like: P.A.W.S. v1.2.0

Download Your Unit

Download the application you want to use (e.g., your_app_name.uwu).

Note: If the developer provided a "Chonk Build", the file might be larger (50MB+). You do not need to install PAWS for Chonk builds; you can skip directly to Step 3.

Run the Application

Method A: Double-Click (Recommended)

Once PAWS is installed, your computer recognizes the file type.

  1. Locate the .uwu file in your file explorer.
  2. Double-click the file.
  3. A terminal window or splash screen may appear briefly while the runtime unpacks the software.
