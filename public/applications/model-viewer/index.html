Supported 3D Format Specifications

Engineering design and manufacturing utilize specialized interchange formats:

Format Geometry Representation Primary Use Case Color/Material Support
STL (.stl) Tessellated triangular facet mesh 3D Printing & rapid prototyping Monochrome mesh
STEP (.stp, .step) Boundary Representation (B-Rep) & NURBS Mechanical CAD/CAM interchange (ISO 10303-21) Assembly hierarchy & body colors
OBJ (.obj) Polygonal surface mesh with normal vectors 3D visualization & reverse engineering Material library (.mtl) / vertex colors
PLY (.ply) Polygon mesh & point clouds Metrology, LiDAR, and surface scans Per-vertex RGB color & normal fields
GLTF / GLB (.gltf, .glb) PBR transmission mesh & scene graph Standard 3D web asset exchange PBR materials, textures, & hierarchy

Native CAD Program Files (.ipt, .sldprt, .catpart)

Native CAD formats (such as Autodesk Inventor .ipt, SolidWorks .sldprt, and CATIA .CATPart) store internal parametric feature trees, sketch constraints, and historical construction operations compiled specifically for proprietary modeling kernels (Autodesk Shape Manager, Parasolid, CGM).

Because these proprietary kernels are closed-source and cannot be executed locally in a web browser without cloud servers, engineers export to the vendor-neutral ISO standard STEP (.stp / .step) format:

Autodesk Inventor (.ipt)
Click File → Export → CAD Format → Select STEP (*.stp, *.step).
SolidWorks (.sldprt)
Click File → Save As → Select STEP AP214 (*.step, *.stp).
PTC Creo / Siemens NX (.prt)
Click File → Export → Select STEP (.stp).
