About Multi-Pendulum Phase Grid

This grid simultaneously integrates an array ($N \times N$) of double pendulums initialized across configuration space where the X and Y coordinates correspond to starting angles $\theta_1$ and $\theta_2$.

Heatmap RGB Color Mapping: Each cell's color encodes real-time angular positions ($R \propto \cos\theta_1, G \propto \cos\theta_2, B \propto \cos(\theta_1+\theta_2)$). In Pixel Mode, this reveals intricate fractal boundaries and bifurcations where tiny shifts in initial angle produce completely different color states.
