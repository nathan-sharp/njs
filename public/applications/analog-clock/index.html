About Analog Clock & Trigonometric SVG Animation

This zero-distraction analog clock is rendered completely using Scalable Vector Graphics (SVG) and manipulated in real-time via client-side JavaScript. Unlike raster image clocks that blur when scaled on high-DPI 4K/8K displays, every hour marker (``) and hand is defined mathematically.

Trigonometric Rotation Mechanics: At every interval, JavaScript calculates the exact angular displacement of each hand around the center coordinate $(100, 100)$:

  • Second Hand: Rotates $6^\circ$ per second ($\frac{360^\circ}{60 \text{ s}}$).
  • Minute Hand: Rotates $6^\circ$ per minute plus a continuous fractional offset of $0.1^\circ$ per second for smooth sweeping motion.
  • Hour Hand: Rotates $30^\circ$ per hour plus $0.5^\circ$ per minute, preventing jarring hour-interval jumps.
