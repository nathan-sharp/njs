Applications

Browser applications and tools that I have built.

Client-Side Engineering & Technical Utilities

Every application listed below runs entirely client-side inside your web browser using modern HTML5, JavaScript, and WebAssembly APIs. There are no backend processing servers, no tracking endpoints, and zero bytes of your input data or uploaded files ever leave your local device.

These tools are built to solve practical day-to-day engineering, mathematical, and data analysis tasks: providing instant, transparent calculations without sign-up barriers, paywalls, or intrusive advertisements.

Angle Converter
Tool for converting between Decimal degrees, Radians and DMS (Degree Minute Second).
Clock
24h clock with ISO 8601 date.
Analog Clock
Minimalistic analog clock with smooth hand movements.
Dither
Convert images and videos to 1-bit black and white using classic algorithms directly in your browser.
Data Mash
A simple web app for encryption, encoding, compression and data analysis.
Double Pendulum
Simulation of a double pendulum using the HTML5 canvas.
Hooke's Law
Interactive demonstration of Hooke's Law with dynamic spring visualization showing displacement, force, and elastic potential energy.
Imager
Client-side image editor, color manipulator, and metadata inspector with direct canvas manipulation.
QR Code Generator
Generate and export QR codes entirely within your browser.
Sine Bar
Calculator for determining gauge block stack heights to set specific angles.
Pi Ledger
Upload a text file of pi digits and compare it against a local reference in your browser.
Radio
Client-side synchronized web radio broadcast using deterministic UTC time modulus.
Talk
Text-to-speech engine that runs locally in the browser.
TDMS Viewer
Interactive oscilloscope and telemetry plotter for LabVIEW TDMS streaming files.
ThreadMate
Thread dimension calculator for Unified Inch (UN), ISO Metric, NPT, and ISO 7-1 (BSPT) threads.
Timer
Web timer based on my Clock application.
Unit Converter
Convert between common units of measurement.
Unified Wrapper Unit (.uwu)
Lightweight container runtime and P.A.W.S. interpreter specification for cross-platform portability.
Minecraft Painting Generator
Create custom Minecraft Bedrock painting texture packs directly in your browser.
