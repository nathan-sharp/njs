About Modular Data Pipelines (`Baking`)

Inspired by professional forensic and developer utilities like CyberChef, Data Mash allows you to construct sequential, multi-stage processing pipelines—often called `recipes`—by chaining atomic operations together. Instead of relying on disparate single-purpose conversion scripts or switching tabs to run Base64 decoding separately from URL decoding, you can stack operations in the Recipe panel and execute them sequentially with a single click of the Bake! button.

Supported Transformations & Encoding Algorithms

Data Mash supports a wide spectrum of essential data manipulation, cryptographic, and encoding algorithms:

  • Data Encoding & Decoding: Convert raw ASCII text or binary streams to and from Base64, Hexadecimal (Hex), and URL / URI Encoding (%-encoding). These transformations are critical when debugging web tokens (such as JWTs), parsing network payload captures, or preparing special characters for HTTP transmission.
  • Cryptographic Hashing: Generate irreversible cryptographic message digests using standard Web Crypto API algorithms including SHA-1, SHA-256, and SHA-512. Hash digests allow developers to verify file integrity, audit API webhooks, and confirm data authenticity without transmitting raw payloads.
  • String & Text Manipulation: Perform structural text operations including upper/lower case conversion, line breaks removal, whitespace trimming, and byte/character counting.

Client-Side Cryptography & 100% Local Processing

When analyzing sensitive API keys, proprietary tokens, system logs, or confidential database strings, sending untrusted text to external online conversion utilities creates severe security vulnerabilities and potential data leaks.

Data Mash runs entirely inside your local web browser. All encoding transformations, cryptographic hashing, and pipeline calculations are executed using native browser JavaScript and the standardized `window.crypto.subtle` API. Absolutely no data is transmitted over the network, no cookies or tracking scripts monitor your inputs, and your processing history remains strictly confined to your device's RAM.
