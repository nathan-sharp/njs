P.A.W.S. Runtime & Binaries

Below are the raw distribution files, installation scripts, and source code for the Platform Agnostic Wrapper Service (P.A.W.S.). For user-friendly setup guides and container overview, please refer to the Unified Wrapper Unit (.uwu) documentation.

Distribution Artifacts

  • Bash Installation Script: `linux_install.sh` (Automates binary placement and `/usr/local/bin` PATH binding)
  • Precompiled POSIX Binary: `paws_linux` (x86_64 ELF executable, statically linked)
  • Raw C++ Runtime Source: `linux_runtime_source.cpp`

C++ Compilation & Runtime Sandbox Theory

The P.A.W.S. daemon (`paws_linux`) is engineered as a zero-dependency C++17 runtime designed to parse `.uwu` archives and execute embedded payloads inside secure POSIX namespaces:

  • Manual Compilation (`g++` / `clang++`): You can compile the raw source directly from terminal using GCC or Clang: g++ -O3 -std=c++17 linux_runtime_source.cpp -o paws_linux -lpthread
  • Memory-Mapped Extraction: Upon execution (`paws run app.uwu`), the daemon maps the archive header into virtual memory, verifies the SHA-256 asset checksums, mounts the embedded filesystem structure via `mmap`, and invokes the designated execution target in an isolated child process.
