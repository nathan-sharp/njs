Sine Bar Calculator

A precision engineering tool for calculating gauge block stack heights to set specific angles.

What is a Sine Bar?

A Sine Bar is a precision measuring instrument used by machinists and inspectors to construct very accurate angles. It consists of a hardened, ground steel bar with two precision cylinders (rollers) attached at the ends. The distance between the centers of these rollers is precisely controlled (typically 5 inches or 100mm).

How it Works

The tool utilizes the trigonometric function Sine to define an angle. When one roller rests on a surface plate and the other is elevated by a stack of gauge blocks, the bar forms the hypotenuse of a right-angled triangle.

The relationship is defined by the formula:

sin(Angle) = Height / Length

Therefore, to find the required height of gauge blocks:

Height = Length × sin(Angle)

Why use it?

  • High Accuracy: Because gauge blocks can be stacked with tolerances in the millionths of an inch (or microns), sine bars can set angles with far greater precision than a protractor or angle gauge.
  • Stability: It provides a rigid, physical reference surface for machining or inspection setups.
