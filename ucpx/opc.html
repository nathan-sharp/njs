Part Definition (.ocp)

The Part file is the atomic unit of the OpenCAD Standard. Unlike current formats, it separates the "Recipe" (how it was made) from the "Result" (the final mesh).

Cloud Native by Design

Modern users rely on SharePoint, Google Drive, or Nextcloud. The OpenCAD standard integrates directly with the WebDAV protocol for locking and versioning.

  • HTTP Works over standard HTTP ports (80/443).
  • LOCK Native WebDAV file locking prevents overwrite conflicts.
  • PROPFIND Custom properties (Material, Mass) exposed as WebDAV properties for search without opening the file.

Path to Standardization

The roadmap for submission to the International Organization for Standardization.

Phase 1: Working Draft (WD)

Define JSON schemas for Part, Elec, and Asm. Develop proof-of-concept converters.

Phase 2: Committee Draft (CD)

Submission to ISO TC 184 (Automation systems and integration). Consensus building with major vendors.

Phase 3: International Standard

Publication of ISO Standard. Integration into WebDAV libraries and CAD kernels.
